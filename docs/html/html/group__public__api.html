Console-parser

Введение

Console-parser - This is an external module for parsing command-line arguments, integrated into UFO Console. It is located in the subdirectory impl/Console-parser/.

https://github.com/onen-touw/Console-parser

Сapability

  • Support for strict and non-strict modes
  • Automatic type conversion (int, float, string, vector)
  • Multiple aliases for options (например, -v,--verbose)
  • Support for comma-separated arrays (--numbers=1,2,3,4)
  • Support for large strings (double quotes) (--message="Hello World")
  • Автоматическое распознавание имени программы (первое слово)

Usage in UFO Console

In UFO Console, the parser automatically parses each input line. It is accessed via the ufo::u_console_msg_block_t::get_opt_list():

console.mk_blank("example", "Example command", [](const ufo::u_console_msg_block_t& bl) {
const auto& parser = bl.get_opt_list();
// Getting value
int value = 0;
if (parser.bind(&value, "-v,--value")) {
bl << "Value: " << value << "\n";
}
// Checking for a flag
if (parser.find("--verbose")) {
bl << "Verbose mode enabled\n";
}
// Getting array
std::vector<int> numbers;
if (parser.bind(&numbers, "-n,--numbers")) {
for (auto n : numbers) {
bl << n << " ";
}
bl << "\n";
}
});

Parsing examples

Arguments

Input string: set --temp=25.5 --mode=fast

float temp;
std::string mode;
parser.bind(&temp, "--temp");
parser.bind(&mode, "--mode");
// temp = 25.5, mode = "fast"

Arrays

Input string: average --values=10,20,30,40

std::vector<int> values;
parser.bind(&values, "--values");
// values = [10, 20, 30, 40]

Double quotes

Input string: echo --message="Hello, World!"

std::string msg;
parser.bind(&msg, "--message");
// msg = Hello, World!

Aliases

Input string: config -p=1234 --verbose

int port;
bool verbose;
parser.bind(&port, "-p,--port"); // найдет по -p
verbose = parser.find("--verbose"); // найдет --verbose

Strict mode

The console is running in strict mode. (parser(true) in constructor of msg_block_t). This means that if there is any error in the command syntax:

  • The parser sets an error flag
  • All bind() operations return false and bind nothing
  • The user sees an error message

◆ u_console_msg_block_t

using ufo::u_console_msg_block_t = typedef __u_console::msg_block_t

Console message block.

This class is used in command callbacks for:

  • Outputting information (operator<<)
  • Accessing the argument parser (get_opt_list())
  • Reading user input (read_line())
  • Console cycle in concole command to execute subprocesses (run_internal())
Заметки
The object is passed to the callback by const reference.
См. также
__u_console::msg_block_t
// Example of use in a command
console.mk_blank("calc", "Simple calculator", [](const ufo::u_console_msg_block_t& bl) {
// Parsing arguments
const auto& parser = bl.get_opt_list();
int a = 0, b = 0;
if (parser.bind(&a, "--a") && parser.bind(&b, "--b")) {
bl << "Result: " << (a + b) << "\n";
} else {
bl << "Usage: calc --a=10 --b=20\n";
}
});

Main console class.

Provides an interface for registration commands and managing the console.

Заметки
The class supports move-only, copying is prohibited.
Предупреждения
The console runs in a single thread
См. также
__u_console::console_t
// Create console
ufo::u_console_t console(&io, 255);
// Command registr
console.mk_blank("status", "Show system status", [](const ufo::u_console_msg_block_t& bl) {
bl << "System is running\n";
});
// Run in thread
ufo::thread task(console.ctask, std::move(console));
